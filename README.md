# Dumy :dove:

> **Dumy** — це десктопний застосунок для трекінгу емоційного стану та саморегуляції. Програма створює заспокійливий, мінімалістичний простір без візуального шуму для щоденної турботи про ментальне здоров'я.

---

### Ціль застосунку
Надати зручний адаптивний інструмент для стабілізації нервової системи, відстеження емоцій та боротьби з вигоранням через персоналізований підбір практик.

---

### Типи користувачів
Застосунок адаптує інтерфейс та контент під три основні профілі:

* :herb: **Лайфстайл (Базовий)** — режим для щоденного використання, трекінгу емоцій та формування корисних тілесних звичок. Підходить для молоді та студентів, які прагнуть підтримувати життєвий баланс.
* :computer: **Фокус та Вигорання** — профіль для людей з інтенсивним розумовим навантаженням (IT-спеціалісти, аналітики), яким потрібні швидкі практики для зняття когнітивної напруги та відпочинку для очей.
* :military_helmet: **Тактичний (Спеціальний)** — стриманий, неагресивний інтерфейс для військових та ветеранів із фокусом виключно на швидке заземлення та відновлення дихання.

---

## Які проблеми вирішує

* **Втрата контролю над емоційним станом:** швидкий трекінг настрою та звичок допомагає вчасно помітити накопичення стресу чи вигорання.
* **Складність підбору практик:** програма автоматично аналізує поточний стан і видає релевантну вправу під конкретний профіль користувача.
* **Відсутність миттєвої допомоги:** ізольований модуль "Заземлення" дозволяє екстрено стабілізувати дихання в один клік під час раптової тривоги.

---

###  Основний функціонал

1. **Щоденник емоцій** — фіксація поточного настрою та збереження історії емоцій і нотаток у базі даних.

2. **Розумна бібліотека практик** — автоматичний підбір порад, дихальних вправ і розтяжки відповідно до емоційного стану користувача.

3. **Модуль «Заземлення»** — дихальна практика з базовою візуальною анімацією для стабілізації стану та відновлення ритму дихання.

4. **Логер звичок** — швидке відмічання сну, випитої води та фокусу одним кліком.

5. **Адаптивний UI** — зміна кольорової палітри та елементів інтерфейсу залежно від обраного профілю користувача.
